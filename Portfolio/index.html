Réalisations

Plateforme d'enseignement

Application Java et gestion d'une API REST pour les services d'enseignement.

Dans ce projet collaboratif de grande envergure, l'objectif était de concevoir une architecture logicielle complète (client-serveur) pour répondre aux besoins réels d'un service d'enseignement. J'ai activement participé au développement du back-end en Java et à la mise en place d'une API RESTful robuste. Le principal défi a été d'assurer une communication fluide, sécurisée et asynchrone entre la base de données centrale et les différentes interfaces utilisateurs (Front-end) en manipulant des données au format JSON.

Architecture Base de Données

Modélisation complète et optimisation SQL pour une entreprise réelle.

L'objectif de ce projet était de partir du besoin brut d'une entreprise existante pour concevoir son système d'information de A à Z. J'ai commencé par la phase de modélisation (MCD, MLD, Schéma Relationnel) pour garantir une structure sans redondance. Au-delà de la simple création de tables, j'ai programmé des requêtes d'analyse complexes en SQL pour le suivi des ventes. J'ai également développé des "Vues" pour simplifier le travail des développeurs, et programmé des "Triggers" sous MariaDB pour automatiser la vérification de l'intégrité de la base.

Moteur de Jeu 2D (C++)

Reprise de code, débogage intensif et application de l'algorithmie en C++.

Ce projet était un véritable défi d'algorithmie et de rétro-ingénierie. À partir d'une base de code complexe fournie par nos professeurs, la mission était de comprendre l'architecture existante pour la déboguer, l'optimiser et y ajouter de nouvelles mécaniques. J'ai dû exploiter au maximum les concepts avancés de la Programmation Orientée Objet (POO) en C++ : héritage, polymorphisme, gestion de la mémoire et pointeurs. Rester bloqué des heures sur un bug complexe m'a appris la rigueur du débogage.

Environnement Linux Embarqué

Configuration système et scripting Python sur Raspberry Pi.

Ce projet m'a permis de sortir du développement logiciel classique pour explorer l'intégration matériel/système. L'objectif était de transformer un Raspberry Pi brut en une véritable station de travail fonctionnelle. J'ai entièrement configuré le système d'exploitation Linux en ligne de commande : gestion rigoureuse des droits utilisateurs via Bash, installation de paquets et sécurisation de l'environnement. Ensuite, j'ai déployé et exécuté des scripts Python interagissant directement avec le système.

Maxspace : Web Design

Création de A à Z de l'identité visuelle d'une entreprise (HTML/CSS).

Projet transversal alliant technique et créativité. L'objectif était de créer de toutes pièces l'identité numérique d'une entreprise fictive de croisière spatiale.
